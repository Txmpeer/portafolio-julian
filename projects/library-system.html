Library Management System

Java · Java Swing · Programación Orientada a Objetos

Aplicación desarrollada en Java para administrar una biblioteca/librería. El sistema permite registrar libros, gestionar membresías, consultar catálogos, realizar préstamos, devoluciones y compras, además de administrar saldos de usuarios.

Objetivo del proyecto

Crear un sistema funcional que simule la operación básica de una librería, integrando lógica de negocio, estructuras de datos, lectura de archivos e interfaz gráfica.

Funciones principales

  • Alta y baja de libros.
  • Registro de membresías.
  • Compra y renta de libros.
  • Devolución de préstamos.
  • Consulta y abono de saldo.
  • Catálogo visual de libros y membresías.
  • Interfaz gráfica con botones, campos de texto y panel de resultados.

Cómo funciona

El proyecto está organizado con clases separadas para representar libros, membresías y la biblioteca. La vista gráfica permite al usuario ingresar datos, mientras que el controlador conecta los botones con las operaciones del sistema.
