Metro CDMX Database Analysis

PostgreSQL · SQL · Data Cleaning · Database Design

Proyecto de análisis y modelado de datos sobre la afluencia diaria del Metro de la Ciudad de México. Se trabajó con más de un millón de registros para construir una base limpia, normalizada y útil para análisis operativo.

Objetivo del proyecto

Diseñar una base de datos relacional que permitiera estudiar patrones de uso del Metro CDMX por fecha, estación, línea, zona, tipo de día y tipo de pago.

Proceso

  • Carga inicial de datos en PostgreSQL.
  • Limpieza de caracteres, duplicados e inconsistencias.
  • Creación de atributos analíticos como tipo de día, semana del año y zona.
  • Normalización del modelo hasta cuarta forma normal.
  • Diseño de diagramas entidad-relación.
  • Consultas SQL para obtener insights operativos.

Principales hallazgos

  • Los días laborales tienen mayor afluencia que los fines de semana.
  • La zona oriente concentra la mayor demanda del sistema.
  • El prepago es el método de pago más utilizado.
  • Las estaciones terminales presentan mayor afluencia promedio.
